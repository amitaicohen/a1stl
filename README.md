# מדריך הפעלה ופריסה: מערכת הבחירות הדיגיטלית לישראל

מערכת בחירות אינטרנטית מלאה הכוללת קלפי דיגיטלית לבוחרים עם פתקי הצבעה רשמיים, אכיפת הצבעה חד-פעמית לפי כתובת IP, לוח בקרה של מנהל הבחירות עם חלוקת 120 מנדטים (חוק בדר-עופר), ומנגנון שיתוף קישור.

---

## 📁 קובצי המערכת

1. **`israel_elections_app.html`**:
   - אפליקציית ווב מלאה (Single-Page WebApp) הפועלת בכל דפדפן (מחשב ונייד).
   - מכילה את ממשק הבוחר, עיצוב פתקים אותנטי, לוח מנהל הבחירות, הדמיית מליאת הכנסת, מודאל שיתוף וסימולטור בדיקת IP.
   - עובדת עצמאית (Client-side) באמצעות `localStorage` וכן מותאמת להתחברות ישירה לשרת Python.

2. **`election_server.py`**:
   - שרת HTTP ו-REST API מובנה ב-Python (אינו דורש התקנת ספריות חיצוניות).
   - מזהה את כתובת ה-IP האמיתית של המשתמש (`Remote IP` או `X-Forwarded-For`).
   - אוכף הגבלה קשיחה של הצבעה אחת בלבד לכל כתובת IP עם שמירה בקובץ נתונים (`elections_data.json`).
   - מבצע חישובי מנדטים בזמן אמת לפי שיטת בדר-עופר ואחוז החסימה (3.25%).

---

## 🚀 הוראות הפעלה

### אפשרות א': הפעלה מקומית ישירה (ללא שרת)
- פתחו את הקובץ `israel_elections_app.html` בלחיצה כפולה בכל דפדפן (Chrome, Edge, Firefox, Safari).
- המערכת תיפתח במצב מקומי מלא.
- ניתן להשתמש בלשונית **"בדיקת IP"** כדי לבדוק חסימת הצבעה כפולה, לדמות כתובות IP שונות ולנהל את הנתונים.

### אפשרות ב': הפעלה כשרת רשת / פריסה מלאה
1. פתחו את הטרמינל בתיקייה שבה נמצאים הקבצים:
   ```bash
   python3 election_server.py 8000
   ```
2. גלשו בדפדפן לכתובת:
   ```
   http://localhost:8000
   ```
3. משתמשים אחרים באותה רשת מקומית או באינטרנט יכולים לגשת דרך כתובת ה-IP של המחשב המארח:
   ```
   http://[YOUR_SERVER_IP]:8000
   ```
4. השרת יזהה אוטומטית את כתובת ה-IP של כל פונה וימנע הצבעות כפולות מאותה כתובת ברמת השרת (קוד שגיאה 403 Forbidden).

## 🗳️ תכונות המערכת

### 1. קלפי לבוחר (Voter Interface)
- **מגש פתקים אותנטי**: עיצוב פתקי ההצבעה בגופן דפוס גדול ובולט וכינוי הרשימה מתחת, בדומה לקלפי אמיתית בישראל.
- **20 רשימות ופתקים**: כל המפלגות הרשומות בישראל (הליכוד - מחל, יש עתיד - פה, המחנה הממלכתי - כן, הציונות הדתית - ט, עוצמה יהודית - ב, ש"ס - שס, יהדות התורה - ג, ישראל ביתנו - ל, הדמוקרטים - אמת, רע"ם - עם, חד"ש-תע"ל - ום, בל"ד - ד, ביחד - רק, ישר - דרך, נעם - ני, המילואימניקים - די, עמך ישראל - ך, ישראל תחילה - י, צעירים בוערים - זך, ופתק לבן).
- **אנימציית מעטפה כחולה**: שלשול הפתק למעטפה רשמית עם סמל המדינה.
- **הגבלת IP**: חסימה מוחלטת של בוחר שכבר הצביע מאותה כתובת IP.

### 2. לוח מנהל הבחירות (Election Director Dashboard)
- ספירת קולות בזמן אמת, קולות כשרים מול פסולים/לבנים.
- בדיקת מעבר אחוז החסימה (3.25% מכלל הקולות הכשרים).
- **אלגוריתם בדר-עופר**: חלוקת 120 מנדטים מלאים על פי מודד כללי וחלוקת עודפים לפי יחס מושב הבא.
- **הדמיית מליאת הכנסת**: תרשים קשתי של 120 מושבי הכנסת בצבעי המפלגות ומד רוב קואליציוני (61 מנדטים).
- **כלי ניהול**: הזרקת 10,000 קולות דמה לבדיקה מהירה, ייצוא ל-CSV ואיפוס נתונים.

### 3. שיתוף קישור (Share Tools)
- שיתוף בלחיצה אחת בוואטסאפ (WhatsApp) עם טקסט הזמנה בעברית.
- שיתוף בטלגרם, טוויטר (X) ופייסבוק.
- העתקת קישור ישיר ללוח (Clipboard).
- קוד QR מובנה לסריקה מהירה בטלפונים חכמים.
