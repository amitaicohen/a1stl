# מערכת הבחירות לכנסת ה-26 (2026) | קלפי אינטרנטית, מסך ניהול מאובטח וסנכרון רשת מלא

מערכת בחירות אינטרנטית מלאה לכנסת ה-26 המאפשרת **הצבעה סימולטנית ממאות ואלפי מכשירים במקביל** (סמארטפונים, טאבלטים ומחשבים ברשת ביתית, משרדית או דרך האינטרנט) עם **סנכרון מלא של תוצאות האמת לאותו מסך ניהול**.

---

## ⚡ מה עודכן במערכת לריבוי מכשירים סימולטני:
1. **הצבעה סימולטנית ממאות מכשירים באותה רשת/Wi-Fi**:
   - זיהוי המכשיר עבר למזהה ייחודי למכשיר (`Voter Device ID`), כך שגם אם מאות אנשים מצביעים מאותה רשת Wi-Fi, משרד או רשת סלולרית (שחולקים את אותה כתובת IP חיצונית) – **כל מכשיר יכול להצביע פעם אחת** וכל ההצבעות נספרות ומצטברות לאותו מאגר תוצאות משותף!
2. **סנכרון מיידי לאותו מסך**:
   - בכל הצבעה, השרת מחזיר מיד את סך הקולות המעודכן מכלל המכשירים.
   - מסך הניהול מושך את תוצאות האמת בזמן אמת (כל 2.5 שניות), כך שכל הצבעה בכל סמארטפון מקפיצה מיד את ספירת הקולות, חישוב המנדטים (בדר-עופר) ותרשים מליאת הכנסת.
3. **שרת מרובה נימים (ThreadingTCPServer)**:
   - שרת ה-Python מעבד כעת בקשות במקביל במבנה Threading ועם מנעול נתונים (`db_lock`) למניעת צווארי בקבוק גם בעומס של מאות מצביעים בו-זמנית.
4. **שני מסכים מוגנים בקוד `2026`**:
   - מסך בוחר נקי ואותנטי ללא חשיפת סקרים או תוצאות.
   - מסך ניהול מוגן בקוד גישה (ברירת מחדל: `2026`).

---

## 🚀 הוראות התקנה והרצה ב-Codespaces

כדי להחיל את העדכון בסביבת העבודה שלך:
```bash
# 1. חילוץ הקבצים המעודכנים ישירות לתיקייה
unzip -o vote.zip

# 2. שחרור הפורט והפעלת השרת
fuser -k 8000/tcp
python3 election_server.py 8000
```

### בדיקת הצבעה משני מכשירים שונים (מחשב + סלולרי):
1. בלשונית **PORTS** ב-Codespaces, ודא שהפורט 8000 מוגדר כ-**Public**.
2. העתק את הכתובת הציבורית (**Forwarded Address**).
3. פתח במחשב אחד והיכנס ללשונית **"מסך ניהול ותוצאות"** עם הקוד **`2026`**.
4. פתח בסמארטפון או במחשב נוסף והצבע לכל מפלגה.
5. **בשנייה שההצבעה נשלחת – מסך הניהול במחשב מתעדכן מיד ומציג את הקול החדש!**
