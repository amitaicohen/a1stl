# מערכת הבחירות לכנסת ה-26 (2026) | קלפי אינטרנטית, מסך ניהול מאובטח וסנכרון רשת

מערכת בחירות אינטרנטית רשמית ומלאה לכנסת ה-26 עם חלוקה ברורה לשני מסכים נפרדים וסנכרון תוצאות בזמן אמת בין כל המכשירים והמחשבים.

---

## 🖥️ חלוקה לשני מסכים נפרדים

1. **מסך הבוחר (קלפי אינטרנטית)**:
   - ממשק הצבעה נקי, אותנטי ואובייקטיבי ללא חשיפת תוצאות או סקרים.
   - כולל את 15 הרשימות (14 מפלגות מרכזיות + פתק לבן) עם אותיות הפתק וכינוי הרשימה הרשמי.
   - כפתור `👥 מועמדים` בכל פתק להצגת 10 המועמדים הרשמיים מוועדת הבחירות המרכזית (2026).
   - כפתור `👁️ מצע` ושקף מצע מרחף (ביטחון, כלכלה, חינוך, גיוס).
   - הטלת פתק אינטראקטיבית עם אנימציית מעטפה כחולה וחסימת הצבעה כפולה לפי IP.

2. **מסך הניהול והתוצאות (מוגן בקוד גישה)**:
   - **כניסה מאובטחת בקוד PIN**: מוגן בקוד גישה (ברירת מחדל: `2026`). כולל מקלדת נומרית נוחה למסכי מגע בסלולר וטאבלט.
   - **סנכרון רשת חי (Realtime Multi-Device Sync)**: מתעדכן אוטומטית כל 3 שניות מול שרת ה-API (`/api/results`), כך שהצבעות מכל סמארטפון או מחשב ברשת מתווספות מיד לתוצאות האמת!
   - אלגוריתם בדר-עופר מלא לחלוקת 120 מנדטים ותרשים קשתי של מליאת הכנסת.
   - מפת 5 הסכמי העודפים הרשמיים והשפעתם.
   - כפתור נעילה והתנתקות `🔒 נעל מסך (התנתק)` וכפתור רענון ידני `🔄 רענן עכשיו`.
   - כלי בקרה וניהול IP למנהל המערכת.

## 🌐 איך להריץ ולפרסם כך שיוכלו להצביע משני מקומות מסונכרנים

### אופציה א': דרך GitHub Codespaces (פתוח לכל העולם!)
1. בטרמינל של ה-Codespaces הריצו:
   ```bash
   python3 election_server.py 8000
   ```
2. בתחתית ה-VS Code, עברו ללשונית **PORTS** (ליד ה-Terminal).
3. לחצו קליק ימני על שורת הפורט **8000** ובחרו:
   `Port Visibility` ➔ **`Public`**.
4. העתיקו את הכתובת הציבורית תחת העמודה **Forwarded Address** (לדוגמה: `https://your-workspace-8000.app.github.dev`).
5. פתחו את הכתובת בסלולרי, טאבלט או במחשב אחר — והצביעו! התוצאות יסתנכרנו מיד ובזמן אמת למסך הניהול!

### אופציה ב': ברשת ה-Wi-Fi הביתית / משרדית
1. הרצו את השרת:
   ```bash
   python3 election_server.py 8000
   ```
2. גלו את כתובת ה-IP המקומית של המחשב שלכם (למשל `192.168.1.50`).
3. מכל טלפון או מחשב המחובר לאותו Wi-Fi גלשו לכתובת:
   `http://192.168.1.50:8000`
